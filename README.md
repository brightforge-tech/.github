# brightforge-tech/.github

Organisation-wide files for [BrightForge Technologies](https://github.com/brightforge-tech):

- `profile/README.md` — the public organisation profile page
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `FUNDING.yml` —
  defaults for every repository that doesn't define its own
- `tools/make_profile_assets.py` — regenerates the banner, avatar and logos
